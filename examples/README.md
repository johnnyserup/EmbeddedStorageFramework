# Examples

This directory contains self-contained usage examples for EmbeddedStorageFramework.

## Planned examples

- `basic_settings/` — Save and load a `Settings` object with `RamStorageDriver`
- `custom_repository/` — Defining and using a custom data type and repository
- `migration/` — Implementing a version migration step

Each example is a standalone CMake project that links against the framework as
a subdirectory.
